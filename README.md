# منصة Shipyard لمتابعة ومعالجة الطلبات

نظام **Shipyard** هو لوحة تحكم تفاعلية (Dashboard) حديثة مصممة لمتابعة وإدارة الطلبات والمبيعات بالدينار الأردني (د.أ) ومخصصة للبيئة والمحافظات الأردنية، بالإضافة إلى أداة برمجية بلغة Python للتحقق من صحة بيانات الطلبات (JSON) وتصدير تقارير ملخصة بصيغة CSV.

---

## 📁 هيكل المجلد (Directory Structure)

```text
ai-workspace/
├── index.html          # الواجهة الرئيسية لمنصة Shipyard (HTML5 - RTL)
├── style.css           # التنسيقات المخصصة ودعم الوضع الليلي والنهاري والتجاوب
├── script.js           # المنطق التفاعلي للوحة التحكم بالدينار الأردني (إحصائيات، فلترة، بحث، إضافة وتصدير)
├── process_orders.py   # سكربت Python للتحقق من صحة بيانات الطلبات وتصدير ملخص CSV بالدينار الأردني
├── sample_orders.json  # بيانات طلبات تجريبية بأسماء ومدن أردنية بصيغة JSON
├── orders_summary.csv  # ملف التقرير الملخص الناتج عن تشغيل سكربت Python (JOD / د.أ)
└── README.md           # ملف توثيق منصة Shipyard وشرح طريقة التشغيل
```

## 🚀 كيفية تشغيل المنصة

### 1. تشغيل لوحة التحكم التفاعلية Shipyard (Web Dashboard)

يمكنك تشغيل اللوحة مباشرة في المتصفح دون الحاجة لأي مكتبات خارجية:

- **الطريقة المباشرة:**
  افتح ملف `index.html` مباشرة عبر أي متصفح ويب.

- **باستخدام خادم محلي عبر Python (مستحسن):**
  ```powershell
  python -m http.server 8000
  ```
  ثم افتح الرابط: `http://localhost:8000`

#### مميزات لوحة تحكم Shipyard:
- **الهوية والعملة:** هوية موحدة لـ **Shipyard** وتتبع مالي متكامل بـ **الدينار الأردني (د.أ)**.
- **توطين أردني:** بيانات واقعية تشمل محافظات المملكة (عمان، إربد، الزرقاء، السلط، العقبة، وغيرها) وأسماء عملاء أردنيين وأسعار متناسبة مع السوق المحلي.
- **إحصائيات لحظية:** تتبع إجمالي الطلبات، الطلبات المكتملة، قيد التنفيذ، وإجمالي المبيعات (مع استثناء الطلبات الملغاة).
- **شريط مرئي لتوزيع الحالات:** نسبة كل حالة (مكتمل، قيد التنفيذ، بانتظار الدفع، ملغي).
- **جدول بيانات تفاعلي:** بحث لحظي، فلترة متقدمة، وترتيب حسب التاريخ أو القيمة.
- **إدارة الطلبات والحفظ التلقائي:** إمكانية تعديل حالة الطلب، حذفه، أو إنشاء طلب جديد عبر النافذة المنبثقة مع الحفظ في `localStorage` (`shipyard_orders`).
- **تصدير التقارير:** تصدير فوري لبيانات الجدول إلى ملف `shipyard-orders-report.csv`.
- **الوضع الليلي والنهاري (Dark/Light Mode)**.

### 2. تشغيل أداة التحقق من البيانات وتصدير التقارير (`process_orders.py`)

يقوم السكربت بقراءة ملف `sample_orders.json`، والتأكد من مطابقة السجلات للحقول المطلوبة وشروط صحة البيانات (مبالغ موجبة أكبر من صفر بالدينار الأردني، اكتمال أسماء العملاء، صحة الحالات)، ثم تصدير الملخص والبيانات المعتمدة إلى `orders_summary.csv`.

#### أمر التشغيل:
```powershell
python process_orders.py
```

#### مخرجات الأداة:
- عرض تقرير فوري في الطرفية يوضح السجلات المستبعدة وأسباب الاستبعاد.
- تحديث ملف `orders_summary.csv` ليحتوي على:
  - **ملخص الحالات بالدينار الأردني (`SUMMARY BY STATUS (JOD / د.أ)`)**: عدد الطلبات، إجمالي المبالغ، ومتوسط قيمة الطلب.
  - **السجلات المعتمدة (`VALIDATED ORDERS (JOD / د.أ)`)**: تفاصيل الطلبات الصالحة.
